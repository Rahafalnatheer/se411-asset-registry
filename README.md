# SE411 Project – Part 1: Computer Asset Registry

React (Vite) frontend to manage company computers: add, display, update, delete. Data is stored in memory only (Part 1).

## Run it
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # run the Vitest suite
npm run build    # production build
```
